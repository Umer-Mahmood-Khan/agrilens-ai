Connect live analysis

The sample walkthrough works immediately. To analyze your own files:

  1. Open .env in the project folder. If missing, copy .env.example to .env.
  2. Add your API key after OPENAI_API_KEY= and save.
  3. Restart the server with npm start, then open the exact URL printed in your terminal.

Keep your key in the local file. Do not paste it into this page or commit it to Git.

Live analysis uses the OpenAI API and sends uploaded files to OpenAI. API charges apply. Set OPENAI_MODEL in .env to change the model.
